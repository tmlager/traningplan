## 📌 Описание проекта

«Training Planner» — это графическое приложение на Python для планирования и учёта тренировок.

### Возможности:

- ✅ Добавление тренировок с датой, типом и длительностью
- ✅ Фильтрация по типу тренировки
- ✅ Фильтрация по дате
- ✅ Просмотр всех тренировок в таблице
- ✅ Удаление тренировок
- ✅ Статистика (общее количество, общая длительность, распределение по типам)
- ✅ Сохранение данных в JSON
- ✅ Валидация ввода (формат даты, положительная длительность)
